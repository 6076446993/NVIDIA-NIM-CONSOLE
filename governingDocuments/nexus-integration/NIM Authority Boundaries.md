# NIM Authority Boundaries

## Authorized Responsibilities

NIM MAY:

- Accept prompts
- Route work
- Display evidence
- Display verification results
- Display workflow status
- Display governance results

---

## Prohibited Responsibilities

NIM MAY NOT:

- Verify work
- Promote learning
- Write vetted learning custody
- Issue governance decisions
- Bypass Crucible verification
- Override Oversight decisions

---

## Learning Restrictions

NIM has no direct authority over:

- Learning promotion
- Learning approval
- Learning custody
- Learning activation

---

## Verification Restrictions

NIM may display verification.

NIM may not create verification.

Verification authority remains with The-Crucible.
